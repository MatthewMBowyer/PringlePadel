Why the reference code matters

EFT, but nobody has to guess

There is no card checkout here on purpose. EFT is the cheapest way for the club to take money — but the bank can't tell you who paid. The booking code solves that: every entry gets a unique reference, so reconciliation is a single search instead of reading a list of names.

  1. Player entersThe form gives them a code like LUX-107 and tells them exactly what to put in the payment reference.
  2. Lea searches the bank appTyping "LUX-" or "MMA-" lists every payment for that event, with the code the payer used.
  3. One tap to confirmMarking the entry paid on the organiser page publishes the name to the event page immediately.

Why not a payment gateway?

Gateways take roughly 2.9% plus a fixed fee per transaction. At R380–R450 an entry, that is real money for a club running one event a month. EFT with a reference code gets most of the benefit for nothing.

  • Card checkout~3% per entry
  • EFT + reference codeR0
  • Manual reconciliation~1 tap per player
