Bank search tip. In your banking app, search the account for LUX- or MMA-. Every player's reference starts with one of those, so the payments for an event list together in date order.

How the code works

The site hands each player a code the moment they enter — for example LUX-104. They are told to put it in the payment reference. When their EFT arrives, the reference on your bank statement is that code, so matching money to entry is one search rather than reading through a list of names.

If someone pays without the code, use the search box above with their surname and confirm them manually.

This test build

Entries live in this browser's storage, so the flow works end to end with no server and no accounts: enter on the booking page, confirm here, then check the event page.

In the real version this same screen reads the Google Sheet, and "Mark paid" writes the confirmation back to it. The buttons do not change.
